## 🎮 游戏规则

### 扫雷游戏规则
- 固定 **7×7 网格**（49个格子）
- 选择扫雷次数：9/12/16/22 次
- 初始保底：**1000W**
- 踩到炸弹💣：保底 **-300W**
- 翻到数字：累计到出红数
- 支持随时导出/导入进度

### 翻翻乐游戏规则
- 选择难度：
  - 简单：4×5（20张牌）- 保底 3688W
  - 中等：5×6（30张牌）- 保底 6688W
  - 困难：5×10（50张牌）- 保底 16688W
- 每次翻开两张牌，相同图片保持翻开
- 配对所有卡片即可获胜
- 支持保底管理和历史记录

### 海克斯游戏规则
- **抽取不同的海克斯 - 开启你的欧皇三角洲之旅吧**
- 老板根据套餐抽取随机三张海克斯卡牌，陪陪根据卡牌内容完成相应任务
- 四种套餐可选：
  - 🥈 **三银尝鲜局**：488元保1888W - 任意抽取三个银色海克斯
  - 🥇 **三金进阶局**：1088元保3288W - 任意抽取三个金色海克斯
  - 🌈 **三彩爽吃局**：2388元保5288W - 任意抽取三个彩色海克斯
  - 🎯 **银金彩雨露均沾**：1288元保3288W - 从银金彩三个牌库分别抽取一个
- **游戏规则说明**：
  1. 撤离失败航天或巴克+60w 监狱+80w
  2. 打手包全卡，是否需要带包可自行商量
  3. 对局中如果发现老板不听打手指挥，对局挂机，导致撤离失败不加保底
  4. 如果撤离失败时老板带出价值超过100w则当局不加保底
  5. 打手严禁卡保底，不允许塞假账(六套、老太头)，除非老板需要

## 📦 部署到 GitHub Pages

1. **在 GitHub 上创建仓库** `yeye-game`

2. **推送代码**
```bash
git add .

git remote add origin https://github.com/1518314680/yeye-game.git

```

3. **开启 GitHub Pages**
   - 进入仓库 Settings → Pages
   - Source 选择 `main` 分支
